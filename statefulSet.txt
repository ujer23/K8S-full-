3. Rollout Commands

These are mainly useful for Deployments.

Check rollout


kubectl rollout status deployment/nginx-dep -n nginx-ns

See rollout history

kubectl rollout history deployment/nginx-dep -n nginx-ns

Update image

kubectl set image deployment/nginx-dep nginx-cont=nginx:1.27 -n nginx-ns

Rollback

kubectl rollout undo deployment/nginx-dep -n nginx-ns

Restart Deployment

kubectl rollout restart deployment/nginx-dep -n nginx-ns
